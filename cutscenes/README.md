# Story cutscenes

Planned beats for the playable vertical slice:

1. **Bangalore office, night** — tired protagonist finishes work.
2. **The call from home** — Ma invites him back for Mahalaya; Baba is quiet.
3. **Childhood photo** — emotional transition from Bangalore to Agartala.
4. **Mahalaya arrival** — airport/railway arrival and auto ride toward Badarghat.
5. **Home reunion** — mother's hug, tea, food and family photos.

The reusable Bengali/English subtitle sequence is in `../story_director.gd`. These beats still need camera blocking, character animation and in-engine validation.

# BHARAT: CITY OF THREE — Windows Prototype

This is a separate Godot 4 project stored alongside the Pandal Hopping project, without replacing its existing files.

## Play on Windows
1. Open the repository's **Actions** tab.
2. Choose **Build BHARAT City of Three (Windows)**.
3. Click **Run workflow** and wait for the job to finish.
4. Open the completed run and download the **BHARAT-CITY-OF-THREE-Windows** artifact.
5. Extract the ZIP and run `BHARAT_CITY_OF_THREE.exe`.

The first build is a playable prototype set in a stylized Tripura-inspired town. It includes three switchable protagonists, Indian streets, shops, vehicles, NPCs, a pond/ghat, highway, safe house and a first food-delivery mission. Geometry is procedural placeholder art; this is not yet AAA-quality finished content.

## Controls
- **WASD** — move / drive
- **Shift** — sprint
- **E** — interact / enter or exit a vehicle
- **1, 2, 3** — switch protagonists (while not driving)
- **M** — mission briefing

The Windows executable is produced by GitHub Actions; Godot source remains available in the `BHARAT-CITY-OF-THREE/project` folder in the build workspace.
